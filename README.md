# Markov Chains

Уже реализовано:

- создан и привязан git-репозиторий;
- подготовлена минимальная структура проекта;
- добавлена простая точка входа для запуска;
- подготовлен минимальный русский датасет для будущего генератора текста;
- данные разложены на исходные и очищенные версии.

Датасет:

- в `data/raw` лежат исходные `.txt`-файлы;
- в `data/processed` лежат очищенные версии этих же текстов;
- в датасете сейчас лежат тексты Чехова и Тургенева;
- из `processed` убраны части служебной разметки, шапки выгрузки и часть лишних примечаний.

Запуск:

```bash
.venv/bin/python src/markov_chain/main.py
```
