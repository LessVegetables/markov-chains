# Markov Chains

Небольшой учебный проект по генерации текста с помощью цепей Маркова на Python. Основная идея простая: модель читает корпус текста, запоминает, какие токены чаще идут друг за другом, и потом на этой основе продолжает фразу.

Сейчас в проекте есть ядро генератора, токенизация, обучение на тексте и файлах, подсчёт статистик модели, сохранение/загрузка через `pickle`, а также простой Streamlit-интерфейс для запуска генерации через браузер.

## Что умеет проект

- Строить цепь Маркова заданного порядка `order`, где состояние — это кортеж из нескольких токенов, а переходы хранятся в таблице вида `state -> next_token -> count`.
- Токенизировать текст, отделяя слова и знаки препинания, а также при необходимости убирать URL, email и нормализовать `ё/е`.
- Обучаться на строке, одном файле, нескольких файлах и на встроенном датасете из текстов русской литературы.
- Генерировать текст от заданного начала, выбирать следующий токен по весам и использовать `temperature`, чтобы делать результат более предсказуемым или более случайным.
- Считать статистики модели: количество состояний, число токенов, branching factor, энтропию и perplexity.
- Показывать результат через Streamlit-приложение с полем ввода и кнопкой `Generate`.

## Структура проекта

- `src/markov_chain/markov_core.py` — главное ядро проекта: токенизатор, класс `MarkovTextGenerator`, обучение, генерация, метрики и сохранение модели.
- `src/app.py` — веб-интерфейс на Streamlit, который загружает модель, принимает стартовую фразу и выводит сгенерированный текст.
- `src/markov_chain/reader.py` — чтение текстов для корпуса.
- `src/markov_chain/main.py` — отдельная точка входа для запуска из кода/консоли.
- `src/markov_chain/test_markov_core.py` — тесты для основной логики генератора.
- `data/` — папка с данными: `raw` для исходников, `processed` для очищенных текстов.

## Как это работает

Сначала текст разбивается на токены, после чего из последовательности строятся состояния длины `order`. Например, при `order=2` модель смотрит на два токена подряд и запоминает, какой токен встречался следующим.

Во время генерации берётся стартовое состояние, затем по таблице переходов выбирается следующий токен, он добавляется в результат, и окно состояния сдвигается дальше. Так шаг за шагом получается новая фраза, похожая по стилю на обучающий текст.

Если стартовая фраза не найдена, высокий уровень API может выбрать случайное стартовое состояние вместо падения с ошибкой. В интерфейсе по умолчанию используется фраза `И он начал`, а модель кэшируется через `@st.cache_resource`.

## Быстрый запуск

### Через консоль

```bash
python src/markov_chain/main.py
```

Параметры запуска:

- `order` — порядок цепи Маркова;
- `max-tokens` — максимальная длина генерации;
- `min-tokens` — минимальная длина до разрешения остановки;
- `temperature` — степень случайности генерации;
- `runs` — количество генераций за один запуск;
- `seed` — фиксирует случайность для повторяемого результата;
- `start-text` — начальный текст, от которого модель попробует продолжить генерацию.

Пример:

```bash
python src/markov_chain/main.py --order 3 --max-tokens 80 --min-tokens 20 --temperature 1.0 --runs 3
python src/markov_chain/main.py --order 2 --start-text "Однажды вечером" --seed 42
```

### Через Docker

```bash
docker build -t markov_chain_streamlit .
docker run -d -p 127.0.0.1:8501:8501 --name markov_chain_app --restart unless-stopped markov_chain_streamlit
```

## Использование из кода

```python
from markov_core import MarkovTextGenerator, Tokenizer

tokenizer = Tokenizer(normalize_yo=True, remove_urls=True, remove_emails=True)
generator = MarkovTextGenerator(order=2, tokenizer=tokenizer)

generator.train_from_text("Текст для обучения. Еще один фрагмент текста.")
text = generator.generate_text(max_tokens=40)

print(text)
```

Полезные методы:

- `train_from_text(text)` — обучить модель на строке;
- `train_from_file(path)` — обучить модель на файле;
- `generate_text(...)` — получить новый текст без ручного выбора стартового состояния;
- `get_statistics()` — получить статистику модели;
- `get_transition_snapshot(limit=20)` — посмотреть часть словаря переходов для отладки.
