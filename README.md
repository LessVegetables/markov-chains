# Markov Chains

Учебный проект по генерации текста на основе цепей Маркова, написанный на Python. Модель читает корпус текста, запоминает, какие токены чаще идут друг за другом, и на этой основе продолжает введённую фразу.

В проекте реализованы: ядро генератора, токенизация, обучение на тексте и файлах, подсчёт статистик модели, сохранение и загрузка через `pickle`, а также простой веб-интерфейс на Streamlit.

## Что умеет проект

- Строить цепь Маркова заданного порядка `order` — состояние представляет собой кортеж из нескольких токенов, переходы хранятся в таблице вида `state -> next_token -> count`.
- Токенизировать текст: отделять слова и знаки препинания, убирать URL и email, нормализовать `ё/е`.
- Обучаться на строке, одном файле, нескольких файлах или на встроенном датасете из текстов русской классической литературы.
- Генерировать текст от заданного начала с поддержкой параметра `temperature` для управления случайностью.
- Считать статистики модели: количество состояний, число токенов, branching factor, энтропию и perplexity.
- Показывать результат через Streamlit-приложение с полем ввода и кнопкой `Generate`.

## Структура проекта

- `src/markov_chain/markov_core.py` — главное ядро: токенизатор, класс `MarkovTextGenerator`, обучение, генерация, метрики и сохранение модели.
- `src/app.py` — веб-интерфейс на Streamlit: загружает модель, принимает стартовую фразу и выводит сгенерированный текст.
- `src/markov_chain/reader.py` — чтение текстов для корпуса.
- `src/markov_chain/main.py` — точка входа для запуска из консоли.
- `src/markov_chain/test_markov_core.py` — тесты для основной логики генератора.
- `data/` — папка с данными: `raw` для исходников, `processed` для очищенных текстов.

## Как это работает

Текст разбивается на токены, из которых строятся состояния длины `order`. Например, при `order=2` модель смотрит на два токена подряд и запоминает, какой токен следовал за ними.

Во время генерации берётся стартовое состояние, по таблице переходов выбирается следующий токен, добавляется в результат, и окно состояния сдвигается на один шаг вперёд. Так получается новая фраза, похожая по стилю на обучающий текст.

Если введённая фраза не найдена в модели, генератор автоматически выбирает случайное начальное состояние из корпуса. В интерфейсе по умолчанию используется фраза `И он начал`, модель кэшируется через `@st.cache_resource`.

## Быстрый запуск

### Через консоль

```bash
python src/markov_chain/main.py
```

Параметры запуска:

- `order` — порядок цепи Маркова;
- `max-tokens` — максимальная длина генерации;
- `min-tokens` — минимальная длина до разрешения остановки;
- `temperature` — степень случайности генерации;
- `runs` — количество генераций за один запуск;
- `seed` — фиксирует случайность для повторяемого результата;
- `start-text` — начальный текст, от которого модель попробует продолжить генерацию.

Пример:

```bash
python src/markov_chain/main.py --order 3 --max-tokens 80 --min-tokens 20 --temperature 1.0 --runs 3
python src/markov_chain/main.py --order 2 --start-text "Однажды вечером" --seed 42
```

### Через Docker

```bash
docker build -t markov_chain_streamlit .
docker run -d -p 127.0.0.1:8501:8501 --name markov_chain_app --restart unless-stopped markov_chain_streamlit
```

## Использование из кода

```python
from markov_core import MarkovTextGenerator, Tokenizer

tokenizer = Tokenizer(normalize_yo=True, remove_urls=True, remove_emails=True)
generator = MarkovTextGenerator(order=2, tokenizer=tokenizer)

generator.train_from_text("Текст для обучения. Ещё один фрагмент текста.")
text = generator.generate_text(max_tokens=40)

print(text)
```

Полезные методы:

- `train_from_text(text)` — обучить модель на строке;
- `train_from_file(path)` — обучить модель на файле;
- `generate_text(...)` — получить новый текст без ручного выбора стартового состояния;
- `get_statistics()` — получить статистику модели;
- `get_transition_snapshot(limit=20)` — посмотреть часть таблицы переходов для отладки.
